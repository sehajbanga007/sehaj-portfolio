# Sehaj Singh Banga — Matchday portfolio

My personal portfolio, built as a football matchday with a music player for navigation.

**Live site:** https://sehajbanga007.github.io/sehaj-portfolio/

## What's inside
- **Players' tunnel** — the entry button dodges you three times before letting you in.
- **Kick-off** — live scoreboard (Sehaj vs Boredom) with a match clock that ticks one minute per second.
- **Pre-match notes** — about me.
- **Match highlights** — education NGO work, IETE-SF committee, this site's beat machine, turf football.
- **Starting XI** — my skills lined up in a 4-3-3 on a pitch. Tap a player for details.
- **Off the pitch** — interests as a tracklist, plus concert ticket stubs.
- **Transfer window** — contact links, and a "medical" where the Barça button refuses to be clicked.
- **Now-playing bar** — each section is a track; prev/next jump between sections, and play starts a house beat (124 BPM) generated live with the Web Audio API.
- **Click to change song** — cycles through Winning Speech (Karan Aujla), SICKO MODE (Travis Scott) and After Party (Don Toliver) using official Spotify embeds (streamed from Spotify, no song files in this repo).
- **Celebrate** — a cut-out of me (with my top scorer trophy) runs in, jumps, spins and lands the SIUUU, timed to the audio clip.
- **Stoppage time** — the footer board counts how many minutes you've spent on the site.
- **Penalty shootout** — five penalties against a keeper who dives at random. Score three to get scouted.
- **Night match mode** — a switch that turns the site dark and fires up stadium floodlights.
- **Football cursor** — on laptops the cursor is a football with a trail when you move fast.
- **Ballon d'Or vote** — Ronaldo or Messi? The Messi button shrinks whenever you get close.
- Extra prank: the tab title changes if you leave the page.

## Built with
Plain HTML, CSS and JavaScript. No frameworks, no templates.
